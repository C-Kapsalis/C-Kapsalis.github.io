Command-line tools
==================

Four independently installable command-line tools for Power BI projects saved
as PBIP and TMDL. Each has a dedicated documentation site and a public source
repository.

tmdl-preflight
--------------

Checks TMDL semantic models and PBIR reports, and safely fixes mechanical
defects.

- Documentation: https://tmdl-preflight-documentation.readthedocs.io/en/latest/
- Source and guide: https://github.com/C-Kapsalis/tmdl-preflight

pbip-model-forge
----------------

Prototypes a Power BI semantic model from a team's questions and prepares a
hand-off specification.

- Documentation: https://pbip-model-forge-documentation.readthedocs.io/en/latest/
- Source and guide: https://github.com/C-Kapsalis/pbip-model-forge

tmdl-drift-doctor
-----------------

Finds and governs drift between a shared template and derived client models.

- Documentation: https://tmdl-drift-doctor-documentation.readthedocs.io/en/latest/
- Source and guide: https://github.com/C-Kapsalis/tmdl-drift-doctor

pbi-plot-styler
---------------

Keeps Power BI report canvases, visual bindings, bookmarks, and themes
consistent.

- Documentation: https://pbi-plot-styler-documentation.readthedocs.io/en/latest/
- Source and guide: https://github.com/C-Kapsalis/pbi-plot-styler

These tools also support the Swift PBI agent skills. Their example models and
outputs use fictional data.
