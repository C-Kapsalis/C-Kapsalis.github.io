SaaS and product work
=====================

Second Read Studio
------------------

Second Read Studio (https://secondread.studio/) is an editorial review
workspace in beta for technical writers, developer advocates, product
marketers, and founders.

The product is designed around a document, precise suggested edits, and the
writer's decision on each change, with an editorial history. Its focus is
reviewing and improving a draft while keeping the author in control. The
open-source Second Read skill is a separate project that informs the product's
editorial approach.
