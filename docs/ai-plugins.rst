AI plugins
===========

The skills are distributed in formats that work with different AI-agent
platforms. A repository is the source of truth for its current setup,
prerequisites, and tested clients.

Second Read
-----------

Includes a Claude Code marketplace plugin, Agent Skills packages, and
platform-specific installation guidance.

- Install and source: https://github.com/C-Kapsalis/second-read#install
- Plugin manifest: https://github.com/C-Kapsalis/second-read/blob/main/plugin.json

Devil's Analyst
---------------

Agent skills and plugin packages for marketing and analytics work. The
repository describes host-specific setup and test coverage.

- Project and installation notes: https://github.com/C-Kapsalis/devils-analyst
- Plugin files: https://github.com/C-Kapsalis/devils-analyst/tree/main/.claude-plugin

Swift PBI
---------

Packages the Power BI skills with platform-specific install instructions.
Running the model and report tools requires a local shell.

- Installation guide: https://github.com/C-Kapsalis/swift-pbi#install
- Plugin files: https://github.com/C-Kapsalis/swift-pbi/tree/master/.claude-plugin

Value Pricing
-------------

Provides a skill and plugin distribution for the pricing workflow.

- Installation guide: https://github.com/C-Kapsalis/value-pricing#install
- Plugin files: https://github.com/C-Kapsalis/value-pricing/tree/main/.claude-plugin

Plugin availability and setup vary by host. Check each project's current
installation guide before installing.
